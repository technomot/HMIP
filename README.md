\# HMIP



Hardware Means of Information Protection — laboratory works.



\## Laboratory Works Repository



This repository contains my laboratory works completed during studies in the \*\*Hardware Means of Information Protection\*\* course. Each lab is organized as a separate folder and demonstrates a practical task related to information security.



\## Contents



\- \*\*Lab1\*\* — Password Protection System: a WPF (C#, .NET) application implementing password-based access control (Variant 6: \*Character sampling\*). Supports administrator and regular user modes, a registered-user list with blocking, and configurable password restrictions.

\- (other labs will be added as work progresses)



\## Features



\- Administrator and regular user modes with separate permissions

\- User accounts stored in a persistent file, created automatically on first run

\- Password confirmation on setup/change, with a limited number of login attempts

\- Configurable password rules (minimum length, character-class mixing)

\- Structured, commented C# source code

\- Help menu with "About the program" information
